# Lab: Your First Foundry Local Model

Build and inspect a local retail reply drafting workflow using the CLI and then Python. Complete both parts of the implementation guide before validation and cleanup. Follow these files in order:

1. [Prerequisites](01-prerequisites.md)
2. [Architecture flow](02-architecture-flow.md)
3. [Implementation steps](03-implementation-steps.md)
4. [Validation checks](04-validation-checks.md)
5. [Troubleshooting](05-troubleshooting.md)
6. [Cleanup](06-cleanup.md)
7. [Proof of execution](07-proof-of-execution.md)

Success means a model answers a prompt locally and you can explain the observed results. A plausible answer alone does not demonstrate factual reliability.
