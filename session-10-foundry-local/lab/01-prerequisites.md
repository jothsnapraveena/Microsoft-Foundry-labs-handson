# 1. Prerequisites

Before starting:

- Use Windows or macOS with a working package manager: WinGet on Windows or Homebrew on macOS.
- For this workshop, plan for at least 8 GB RAM and 5 GB free disk space; 16 GB RAM and 10 GB free disk space give more room. Larger models may need substantially more memory and storage.
- A GPU is optional for the exercise; choose a model that fits your device.
- Check available disk space and close memory-intensive applications.
- Arrange internet access for setup and model download.
- Use a terminal where installation is permitted by your device policy.
- Use only the fictional prompts supplied here for the exercise.


For the SDK section, install Python 3.11 to 3.13 and create a dedicated virtual environment. Native wheels must support your OS and architecture.

This session does not require an Azure subscription, a Foundry project, or an API key.
